# 單機報價管理系統（FUN 學院文理補習班）

一套跑在**自己電腦**上的報價管理小工具：管理學生、課程價目、開立報價單、
追蹤繳費狀態，並**一鍵匯出 Word 報價單**（版面照你的格式，可再自由編輯）。

- 資料存在單一檔案 `補習班.db`（SQLite，免安裝資料庫伺服器）
- Word 由 `範本/報價單範本.docx` 套版產生 —— **改版面只要用 Word 改這個範本，不用動程式**
- 介面用瀏覽器操作，但只開在 `localhost`，不對外、不需要主機

---

## 一、安裝（第一次才需要）

需要電腦有 Python 3.9+。在本資料夾開啟終端機，執行：

```bash
pip install -r requirements.txt
```

## 二、啟動

```bash
python app.py
```

看到 `Running on http://127.0.0.1:5000` 後，用瀏覽器打開 **http://127.0.0.1:5000** 即可。
要關閉就回到終端機按 `Ctrl + C`。

> 想放一筆範例資料（陳楷元＋課輔班／美語班）方便試玩，先執行一次：
> `python seed.py`

## 三、怎麼用

| 頁面 | 功能 |
|------|------|
| **總覽** | 看學生數、報價單數、未結清筆數、已收金額 |
| **學生名冊** | 新增／編輯／刪除學生，開報價時可直接選 |
| **課程／價目** | 維護課程與預設學費、教材費，開報價時自動帶入 |
| **開立報價單** | 選學生→加課程列（可選價目自動帶價或手打）→建立→下載 Word |
| **報價歷史** | 查所有報價、重新下載 Word、更新繳費狀態、記收據編號 |

**計算規則**：每列 `總計 = 學費 + 教材費 − 扣除金額`；小計自動加總；金額 0 的欄位留白。
日期用自由文字（可填民國年，例 `115/6/1-115/6/30`），不自動換算。

## 四、改報價單版面（保留你的彈性）

直接用 Word 打開 **`範本/報價單範本.docx`** 修改：字體、logo、條款、繳費資訊、
表格樣式都可以改。只要**保留**裡面的佔位符即可：

| 佔位符 | 意義 |
|--------|------|
| `{{ student_name }}` | 學生姓名 |
| `{% tr for c in courses %}` … `{% tr endfor %}` | 課程明細列（自動依課程數重複，勿刪這兩列）|
| `{{ c.name }}` `{{ c.date }}` `{{ c.tuition }}` `{{ c.material }}` `{{ c.deduction }}` `{{ c.total }}` | 各課程欄位 |
| `{{ sum_tuition }}` `{{ sum_material }}` `{{ sum_deduction }}` `{{ sum_total }}` | 小計 |
| `{{ note }}` | 備註 |

繳費方式、匯款帳號等固定文字，直接在範本裡改字即可。

> 若想從程式重建範本（例如大改結構），改 `build_template.py` 後執行
> `python build_template.py` 會重新產生範本檔。

## 五、檔案結構

```
報價系統/
├─ app.py              本機操作介面（Flask）
├─ db.py               SQLite 資料層（學生／課程／報價／明細）
├─ quote_docx.py       報價資料 → Word 套版
├─ build_template.py   產生 Word 範本（可重現）
├─ seed.py             灌入範例資料
├─ 範本/報價單範本.docx  Word 範本（可自由編輯版面）
├─ templates/          網頁畫面
├─ static/             內建 Bootstrap（離線可用）
├─ 補習班.db            你的資料（自動產生，不進版控）
└─ 輸出/                產生的 Word（自動產生，不進版控）
```
