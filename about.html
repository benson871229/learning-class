授課方式詳介

多元彈性的教學模式，適合不同學習需求

👤

一對一個人教學

完全依照學生個別進度進行，是效率最高的學習方式。老師能即時針對學生的弱點進行強化，並隨時調整教學內容。

  • ✓ 完全個人化教學計畫
  • ✓ 彈性上課時間安排
  • ✓ 學習狀況即時追蹤
  • ✓ 弱點強化最有效率
👥
推薦

小班制教學（2–4人）

兼顧個別差異與同儕學習的最佳選擇。學生可互相討論、激發思考，費用也比個人教學更經濟實惠。

  • ✓ 同儕互動促進學習
  • ✓ 費用合理經濟實惠
  • ✓ 老師仍可關注每位學生
  • ✓ 競爭氛圍提升積極性
🏫

大班制教學（5人以上）

採系統化課程進行，適合基礎穩固、自律性高的學生。擁有最實惠的學費，並享受豐富的課堂資源。

  • ✓ 課費最為經濟實惠
  • ✓ 系統化課程設計
  • ✓ 豐富講義與習題
  • ✓ 定期測驗評量進度
