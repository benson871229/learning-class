# 報價單產生器（輕量 HTML 版）

**雙擊 `報價單.html` 就能用**——不用安裝 Python、不用架伺服器、不用資料庫。
學生與課程資料由你在 **Excel** 維護，一次產出兩種 Word 單據，都可再自由編輯：

| 單據 | 版面 | 說明 |
|---|---|---|
| **繳費單** | A5 橫式 210×148mm | 課程明細、小計、繳費方式 |
| **收據** | A4 直式 210×297mm | 同一頁**三聯**可裁開，分壽豐路／翠屏路兩分校 |

**收據的姓名、班別、金額全部自動沿用繳費單的資料**，不必重打；
「實收金額」會自動換算成國字大寫（例：12500 → 新台幣壹萬貳仟伍佰元整）。

---

## 一、怎麼用

1. 用瀏覽器打開 **`報價單.html`**（雙擊即可，建議 Chrome / Edge）
2. 點「**載入學生名冊**」「**載入課程價目**」選你的 Excel（可略過，直接手動輸入）
3. 選學生 → 加課程列（選課程會自動帶入費用）→ 填日期、備註
4. 要開收據的話，選「**收據分校**」（壽豐路／翠屏路）
5. 按「**下載繳費單**」或「**下載收據**」

> 分校只影響收據的抬頭與班址，繳費單不分校。
> 收據的「修業期間」由課程的日期起訖自動換算（`115/9/1-115/9/30` → `自115年9月1日起至115年9月30日止`）。

> 需要對帳時，按「**匯出紀錄 Excel**」會把這張報價單存成一份 Excel。

## 一之二、一次印很多份（批次合併）

要開 70 份報價單時，不必下載 70 個檔案。**批次合併會把多份合成「一個」Word，
每位學生各占一頁，列印一次就全部印完。**

有兩種方式把報價單放進批次清單，可以混用：

**A. 用 Excel 一次匯入（適合大量）**

準備一份「報名清單」，**每一列是一筆課程**，同一位學生有幾門課就寫幾列，
系統會自動依姓名合併成一份報價單：

| 學生姓名 | 課程名稱 | 日期起訖 | 學費 | 教材費 | 扣除金額 | 開立日期 | 備註 |
|---|---|---|---|---|---|---|---|
| 陳楷元 | 課輔班 | 115/6/1-115/6/30 | 6000 | 0 | 0 | 115/6/1 | |
| 陳楷元 | 美語班 | 115/6/1-115/6/30 | 3000 | 0 | 1000 | 115/6/1 | 英文班每月計8堂課 |
| 林曉薇 | 數學班 | 115/6/1-115/6/30 | 4000 | 500 | 0 | 115/6/1 | |

↑ 這份清單會產生 **2 份**報價單（陳楷元 2 門課、林曉薇 1 門課）。

必要欄位：**學生姓名**、**課程名稱**、**學費**。一次上限 500 份。

**B. 一份一份手動加（適合零星幾份）**

填好上面的表單後，按「**＋ 把目前這份加入批次**」，再填下一位。

**最後按「📚 合併繳費單」或「🧾 合併收據」** → 各得到一個檔，每位學生一頁。

> 「📊 匯出批次紀錄 Excel」會把所有份數匯成一張總表，方便對帳。

## 三、改報價單版面

點頁面上的「**更換繳費單範本**」或「**更換收據範本**」，載入你用 Word 改過的 `.docx` 即可。
版面、字體、logo、條款、匯款資訊都能改，只要**保留佔位符**。

**繳費單**（`範本/繳費單範本.docx`）

| 佔位符 | 意義 |
|--------|------|
| `{student_name}` | 學生姓名 |
| `{#courses}` … `{/courses}` | 課程明細列（放在表格同一列的頭尾格，會依課程數自動重複）|
| `{name}` `{date}` `{tuition}` `{material}` `{deduction}` `{total}` | 各課程欄位 |
| `{sum_tuition}` `{sum_material}` `{sum_deduction}` `{sum_total}` | 小計 |
| `{note}` | 備註 |

**收據**（`範本/收據範本.docx`，三聯各一份，同名佔位符會一起填）

| 佔位符 | 意義 |
|--------|------|
| `{branch_title}` `{branch_addr}` | 分校抬頭與班址（依所選分校）|
| `{student_name}` | 學生姓名 |
| `{class_name}` | 班別（所有課程名稱以 `+` 串接）|
| `{period}` | 修業期間（由課程日期換算）|
| `{amount}` `{amount_cn}` | 金額數字／國字大寫 |

補習班證號與電話兩分校相同，屬固定文字寫在範本裡；要改直接編輯範本即可。

改完若要設成**內建預設**，執行 `python3 embed_template.py`。
`範本/原始檔/` 保留你提供的原稿，`python3 build_templates.py` 可從原稿重新產生範本。

## 四、資安說明

你特別在意 **LFI（本地檔案包含）**，這裡說明為什麼這個版本沒有這個風險：

**LFI 是伺服器端漏洞**——後端拿使用者輸入去讀檔／include 才會發生。
這個版本**完全沒有伺服器**，程式只在你的瀏覽器裡執行，因此
**LFI、路徑穿越、SSRF、SQL Injection 這類伺服器端漏洞在結構上不可能存在**。

其餘實際做的防禦（皆已實測驗證）：

| 風險 | 防禦方式 |
|------|----------|
| **資料外洩** | CSP `connect-src 'none'`：頁面無法對外連線，資料不可能被送出 |
| **XSS**（惡意 Excel 內含 `<script>`）| 所有外來字串一律用 `textContent` 渲染，從不使用 `innerHTML` |
| **原型汙染** | Excel 轉物件時用 `Object.create(null)`，並過濾 `__proto__`／`constructor`／`prototype` 欄位 |
| **Excel 公式注入** | 匯出時對 `=` `+` `-` `@` 開頭的值加前置單引號，Excel 視為純文字 |
| **XXE** | 以瀏覽器 `DOMParser` 解析 XML，不處理外部實體 |
| **Zip bomb／記憶體耗盡** | 限制檔案大小（15MB）、解壓大小、列數（20000）與欄數（256）|
| **惡意檔名** | 下載檔名移除路徑分隔與控制字元 |
| **供應鏈風險** | 不使用有已知漏洞的 `xlsx` 套件（見下），無 CDN、無外部相依 |

**關於 Excel 函式庫**：npm 上最新的 `xlsx@0.18.5` 有 high 等級漏洞且官方標示
「No fix available」（原型汙染 GHSA-4r6h-8v6p-xvw6、ReDoS GHSA-5pgg-2g8v-p4x9），
且體積達 5.1MB。因此本專案改用自寫的 `lib/xlsx-lite.js`（約 12KB），
無已知漏洞、體積小、解析行為完全可控。

## 五、檔案結構

```
報價單_HTML/
├─ 報價單.html              ← 雙擊這個
├─ app.js                   介面邏輯
├─ lib/                     程式庫（需與 HTML 放一起）
│   ├─ pizzip.min.js        zip 讀寫
│   ├─ docxtemplater.min.js Word 套版
│   ├─ FileSaver.min.js     下載
│   ├─ xlsx-lite.js         自寫的輕量安全 Excel 讀寫
│   └─ templates.js         內建的繳費單＋收據範本（base64）
├─ 範本/
│   ├─ 繳費單範本.docx        可用 Word 自由編輯
│   ├─ 收據範本.docx          可用 Word 自由編輯
│   └─ 原始檔/               你提供的原稿，供重新產生範本用
├─ 範例資料/                 students.xlsx、courses.xlsx、報名清單.xlsx
├─ build_templates.py       （選用）從原始檔重新產生範本
├─ embed_template.py        （選用）把範本設為內建預設
└─ make_sample_roster.py    （選用）產生報名清單範例
```

> `lib/` 與 `報價單.html` 必須放在一起，分開就無法運作。
> 要搬到別台電腦，整個 `報價單_HTML` 資料夾複製過去即可。
