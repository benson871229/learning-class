# learning-class

補習班網站 + 報價單產生器。

---

## 📄 要開報價單？打開這一個檔案

```
報價單_HTML/報價單.html      ← 雙擊它
```

**其他檔案都不用管**，它們是這個檔案運作需要的零件。

### 怎麼用

1. 雙擊 `報價單_HTML/報價單.html`（建議用 Chrome 或 Edge）
2. 填「學生姓名」和「開立日期」
3. 填課程名稱、日期、學費（多門課就按「＋新增課程列」）
4. 按 **「📄 下載 Word 報價單（B5）」**

下載的 Word 可以直接編輯、列印。

### 要一次開很多份？用「批次合併」

在頁面的第 5 區，可以把多份報價單合成**一個** Word 檔，每位學生各占一頁，
列印一次就全部印完，不用下載幾十個檔案。

- 份數多：準備一份「報名清單」Excel（每列一筆課程，依學生姓名自動分組），一次匯入
- 份數少：填完一份按「＋ 把目前這份加入批次」，再填下一位

詳細欄位格式見 [`報價單_HTML/README.md`](報價單_HTML/README.md)。

### 想用 Excel 管學生和課程（選用）

照 `報價單_HTML/範例資料/` 裡兩個範例檔的格式，換成你自己的資料：

- `students.xlsx` — 需要「**學生姓名**」欄
- `courses.xlsx` — 需要「**課程名稱**」「**學費**」欄

然後在頁面的步驟 1 載入它們，之後就能用下拉選單選學生、選課程自動帶價格。

### 想改報價單版面

用 Word 打開 `報價單_HTML/範本/報價單範本.docx` 修改，再從頁面上的
「更換 Word 範本」載入即可。詳細說明見 [`報價單_HTML/README.md`](報價單_HTML/README.md)。

> ⚠️ `報價單.html` 和 `lib` 資料夾必須放在一起，分開就無法運作。
> 要搬到別台電腦，整個 `報價單_HTML` 資料夾複製過去。
